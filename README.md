\# Fake Job Post Detection



An NLP-based machine learning system for detecting fraudulent job postings.



\## Technologies



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- TF-IDF

\- Logistic Regression



\## Methodology



The system applies text preprocessing and TF-IDF feature extraction to convert job descriptions into numerical feature vectors. A Logistic Regression classifier is then trained to classify job postings as legitimate or fraudulent.



\## Dataset



Kaggle Fake Job Postings Dataset.



\## Machine Learning Pipeline



Job Posting → Text Preprocessing → TF-IDF → Logistic Regression → Classification
